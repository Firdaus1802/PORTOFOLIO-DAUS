## Cara Menjalankan Proyek Secara Lokal

### Prasyarat
- Node.js versi 18.18 atau lebih tinggi
- npm atau pnpm

### Langkah Instalasi

1. Clone repositori ini:
   ```bash
   git clone https://github.com/Firdaus1802/PORTOFOLIO-DAUS.git
   cd PORTOFOLIO-DAUS
   ```

2. Install seluruh dependensi:
   ```bash
   npm install
   ```

3. Jalankan development server:
   ```bash
   npm run dev
   ```

4. Buka peramban dan akses alamat:
   ```
   http://localhost:3000
   ```

5. Build untuk produksi:
   ```bash
   npm run build
   npm run start
   ```
