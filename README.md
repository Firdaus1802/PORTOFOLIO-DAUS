## Getting Started

### Prerequisites
- Node.js 18.18 or higher
- npm or pnpm

### Installation

```bash
git clone https://github.com/Firdaus1802/PORTOFOLIO-DAUS.git
cd PORTOFOLIO-DAUS/portofoliov2-master
npm install
```

### Local Development

```bash
npm run dev
```

Application will run locally at `http://localhost:3000`.

### Production Build

```bash
npm run build
npm run start
```
