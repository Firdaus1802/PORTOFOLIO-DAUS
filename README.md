## 🚀 Proyek Unggulan (Featured Projects)

### 1. Finzie Joki Service
* **Kategori**: Web Application & Game Service Platform
* **Tech Stack**: Next.js, React, JavaScript, Tailwind CSS, Vercel
* **Live Demo**: [finziejokiservice.vercel.app](https://finziejokiservice.vercel.app/)
* **Deskripsi**: Platform penyedia layanan game service Roblox terpercaya dengan antarmuka modern responsif, katalog layanan terstruktur, dan direct order WhatsApp admin.

### 2. Data Mining - Market Basket Analysis (Kelompok 4 UG)
* **Kategori**: Flutter Web App & Data Analytics
* **Tech Stack**: Flutter, Dart, Algoritma Apriori, Netlify Cloud
* **Live Demo**: [data-mining-kelompok-4.netlify.app](https://data-mining-kelompok-4.netlify.app/)
* **Deskripsi**: Aplikasi analitika transaksi konsumen Universitas Gunadarma untuk menganalisis Market Basket Analysis menggunakan Algoritma Apriori dengan kalkulasi otomatis nilai Support, Confidence, dan Lift Ratio.

### 3. Interactive Portfolio Website & AI Assistant
* **Kategori**: Personal Portfolio & Generative AI Assistant
* **Tech Stack**: Next.js (App Router), TypeScript, Tailwind CSS, Framer Motion, Edge AI
* **Deskripsi**: Web portofolio interaktif dengan animasi halus, credential viewer terverifikasi, CV viewer siap cetak (A4), dan AI Chatbot Assistant cerdas.

## ✨ Fitur Utama

- **Tampilan Modern & Responsif**: Optimal untuk layar ponsel pintar, tablet, laptop, hingga monitor desktop.
- **Animasi Halus & Interaktif**: Menggunakan Framer Motion dan efek interaksi 3D Glare Hover.
- **Katalog Proyek Terintegrasi**: Dilengkapi kartu proyek, rincian modal fitur utama, badge status deployment, dan tautan live website.
- **Firdaus Assistant (Chatbot AI)**: Asisten cerdas terintegrasi untuk menjawab pertanyaan seputar profil, keahlian, dan proyek secara instan.
- **Credential & Certificate Modal**: Pratinjau sertifikasi industri terverifikasi (Cisco, BNSP, Dicoding, dll).
- **Curriculum Vitae (CV)**: Halaman CV interaktif dengan dukungan format cetak A4 ramah printer.

## 💻 Cara Menjalankan Proyek Secara Lokal

1. **Clone repositori ini**:
   ```bash
   git clone https://github.com/Firdaus1802/PORTOFOLIO-DAUS.git
   cd PORTOFOLIO-DAUS
   ```

2. **Install dependensi**:
   ```bash
   npm install
   ```

3. **Jalankan development server**:
   ```bash
   npm run dev
   ```

4. Buka browser dan akses [http://localhost:3000](http://localhost:3000).

5. **Build untuk Production**:
   ```bash
   npm run build
   npm run start
   ```
